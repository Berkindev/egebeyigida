- **Öne çıkanlar (kapakları marka renklerinde):** Avokado · Enginar · Egzotik · Teslimat · Nasıl Sipariş · SSS

### 2.3 Şablonlar (tasarım spesifikasyonu)
- Renkler: kahve `#43241A`, zeytin `#ABAD3A`, krem `#FAF6EE`. Font: Fraunces (başlık) + Instrument Sans (metin). Site ile aynı.
- Formatlar: 1080×1350 (gönderi/carousel), 1080×1920 (hikâye/Reels kapağı), 1080×1080 (GBP için).
- Şablon setleri:
  1. **Ürün kartı:** büyük fotoğraf + alt şeritte ürün adı + 2 özellik (kalibre/ambalaj) + "Fiyat & katalog: WhatsApp"
  2. **Bilgi carousel'i (5–7 kart):** kapak sorusu → maddeler → son kart CTA
  3. **Karşılaştırma kartı:** iki sütun (Hass | Fuerte), siteyle aynı tablo dili
  4. **Duyuru/sezon:** "Yerli Hass sezonu başladı" tipi kısa duyuru
  5. **Hikâye CTA'sı:** "Bu haftanın fiyat listesi için DM / WhatsApp"
- Üretim yolu: Canva marka kiti (mevcut Canva kapakları baz alınır) **veya** repo içinde HTML şablon + otomatik PNG üretimi (site verisinden ürün kartı basma). Karar sonraki oturumda.
